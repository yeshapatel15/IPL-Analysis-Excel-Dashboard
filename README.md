# IPL-Analysis-Excel-Dashboard

## 📌 Project Overview
An interactive IPL (Indian Premier League) Analysis Dashboard created in Microsoft Excel to analyze season-wise performance, team statistics, venue insights, and player achievements using data visualization techniques.

---

## ✨ Key Features
- Season-wise IPL winner and runner-up analysis
- Player of the Match statistics
- Bat First vs Field First winning comparison
- Venue-wise winning trends
- Title winner comparison across teams
- Top performers with most Man of the Match awards
- Interactive dashboard using slicers and filters

---

## 🛠️ Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
